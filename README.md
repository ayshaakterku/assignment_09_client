# 🎓 MentorLagbe – Smart Tuition & Mentorship Platform

## 🎯 Project Purpose

MentorLagbe is a smart mentorship platform designed to connect students and learners with experienced mentors who can guide them throughout their academic, professional, and personal development journeys.

The primary goal of this platform is to make finding the right mentor easier, faster, and more accessible. Users can explore mentor profiles, discover their expertise, and connect with mentors based on their learning goals, interests, and career aspirations.

MentorLagbe aims to create opportunities for knowledge sharing, skill development, career guidance, and meaningful mentor-learner relationships.

# Next.js template

This is a Next.js template with shadcn/ui.

## Adding components

To add components to your app, run the following command:

```bash
npx shadcn@latest add button
```

This will place the ui components in the `components` directory.

## Using components

To use the components in your app, import them as follows:

```tsx
import { Button } from "@/components/ui/button";
```
